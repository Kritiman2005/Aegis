# Professional Tone

## Instructions

When drafting or rewriting text for a professional audience:

1. Use complete sentences and standard grammar — no emojis, no slang, no exclamation points unless the source text had them for a clear reason.
2. Keep sentences reasonably short. Prefer plain words over jargon unless the audience clearly expects domain terminology.
3. Lead with the point. Put the ask, decision, or key fact in the first sentence or two — don't bury it.
4. Match the level of formality to what was asked: "professional" is warmer and more direct than "formal," which can read stiff and legalistic. Default to professional unless the user says formal.
5. Keep the original meaning and every factual detail intact. Only change tone and phrasing, never the substance, unless asked to also edit content.
6. For emails specifically: a short, clear subject line if one is needed, a direct opening line, and a plain sign-off — no filler like "I hope this email finds you well" unless the user's own draft already had a similar opener.

## Example

Input: "hey can u send me the report by friday thanks"

Output: "Could you send me the report by Friday? Thanks."
